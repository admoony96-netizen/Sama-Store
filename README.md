# سيرفر سما ستور — حساب سلة شي إن

سيرفر بسيط (Node.js + Express + Playwright) يستقبل رابط سلة من شي إن،
يفتحه بمتصفح مخفي، يقرا سعر كل قطعة، ويحسب المجموع بالدينار العراقي
(سعر الدولار الحالي: **1320** — عدّله من متغير `USD_TO_IQD` داخل `server.js`).

لا يوجد كلفة شحن مضافة، حسب طلبك.

## 1. التشغيل على جهازك (تجربة محلية)

```bash
cd server
npm install
node server.js
```

أول مرة، أمر `npm install` راح ينزّل متصفح Chromium تلقائياً (عبر
`postinstall`). إذا ما نزل، شغّل يدوياً:

```bash
npx playwright install chromium
```

السيرفر يشتغل افتراضياً على `http://localhost:3000`.

للتأكد إنه شغال، افتح بالمتصفح: `http://localhost:3000/health` —
لازم يرجعلك `{"ok":true}`.

## 2. اختبار سريع بدون واجهة

```bash
curl -X POST http://localhost:3000/api/calculate \
  -H "Content-Type: application/json" \
  -d '{"cartUrl":"ضع رابط سلة حقيقي هنا"}'
```

## 3. مهم جداً — الـ selectors محتاجة تأكيد

ما گدرت أختبر الكود على موقع شي إن الحقيقي لأن بيئة التطوير عندي بلا
إنترنت. كتبت الكود بأسماء عناصر (`class`) شائعة بصفحات سلة شي إن، بس
شي إن تغيّر تصميم موقعها من وقت لوقت.

**إذا شغلت السيرفر وطلع خطأ "ما گدرت أگرا محتوى السلة"، أو الأرقام غلط:**

1. افتح رابط سلة حقيقي بالمتصفح (كروم مثلاً)
2. اضغط كليك يمين على سعر أي قطعة > Inspect
3. انسخ الـ HTML اللي يظهر (السطر أو اثنين اللي فيهم السعر، والي فيهم
   الكمية)
4. ابعثلي هذا الـ HTML وأعدل السيرفر يقرا الأسعار بدقة 100%

النقاط اللي تحتاج تعديل محددة بعلامة `TODO` داخل `server.js`.

## 4. رفع السيرفر أونلاين (production)

هذا السيرفر لازم يشتغل على سيرفر حقيقي (VPS) وليس استضافة استاتيكية
عادية، لأنه يشغل متصفح Playwright بالخلفية. خيارات سهلة:
- **Railway** أو **Render**: يدعمون Node.js + Playwright مباشرة
- **VPS** (مثل Hetzner أو DigitalOcean): تنصب Node.js وتشغل السيرفر
  بواسطة `pm2` حتى يضل شغال دايماً

بعد ما ترفعه، خذ الرابط النهائي (مثلاً `https://api.samastore.com`)
وحطه بمكان `API_BASE` داخل ملف `index.html` تبع الواجهة.

## 5. ملاحظات أمان بسيطة

- حط `cors` يسمح فقط لدومين موقعك بدل السماح للجميع، قبل ما تطلعه
  للعلن (حالياً مفتوح للجميع لتسهيل التجربة).
- حط حد أقصى لعدد الطلبات (rate limit) حتى ما يصير فيه استخدام مفرط
  للسيرفر من أي شخص يلگط الرابط.
